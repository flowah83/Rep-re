### Revenir à la version d’avant

Les séances restent dans le téléphone (IndexedDB), pas dans le site. Pour revenir en arrière : restaurer le commit précédent sur `main` et laisser le déploiement GitHub Pages se refaire. Les données locales ne sont pas effacées. Une copie `repere-….json` (Réglages › Créer une copie) permet de réimporter si un jour le navigateur est vidé. Une copie ancienne, sans modèles ni matériel, s’importe encore.
